// 04 — postmortems

Selected incidents

RESOLVED

Thread starvation from duplicate report requests

A spike in 423/409 errors on the reporting service correlated with ECS task OOM and task bounce. Root cause: duplicate "generate report" clicks for the same case ID were piling up threads, exhausting the pool and creating memory pressure.

Fix → idempotency + request deduplication proposed at the API layer, filed via Jira
RESOLVED

Aurora History List Length climbing with no visible long-running transaction

RDS CPU looked normal while HLL quietly grew. Traced to idle Sleep-state connections pinning old read views, plus a long-running query on a reader stalling purge on the writer via Aurora's shared storage.

Fix → two-tier response: surgical kill of offending Sleep sessions, then incremental compute drain if needed
